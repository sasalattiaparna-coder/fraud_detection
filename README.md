# 💳 Bank Fraud Detection using Machine Learning

## 📌 Overview
This project is an AI-based fraud detection system that identifies suspicious transactions in real time using machine learning techniques.

---

## 🚀 Features
- 🤖 Machine Learning models (Logistic Regression, Random Forest, XGBoost)  
- ⚖️ Handles imbalanced data using SMOTE  
- ⚡ Real-time fraud detection using FastAPI  
- 🎛️ Interactive dashboard using Streamlit  
- 📊 Probability-based fraud prediction  

---

## 🛠️ Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn, XGBoost  
- Imbalanced-learn (SMOTE)  
- FastAPI  
- Streamlit
